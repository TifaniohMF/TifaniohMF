## 🚀 Featured Project

### Linear System Solver
[![Linear System Solver](https://img.shields.io/badge/💻-math-013243?style=for-the-badge&logo=math&logoColor=white)](https://github.com/TifaniohMF/SolveLinearSystem)

A Python tool for solving systems of linear equations efficiently. The project explores computational methods for systems of the form $A\mathbf{x} = \mathbf{b}$, where $A \in \mathbb{R}^{n \times n}$ and $\mathbf{x}, \mathbf{b} \in \mathbb{R}^n$.
